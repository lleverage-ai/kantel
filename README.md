# harbour
Agent platform: sessions, sandboxes (isolate + container), workspace, browser, vault, audit, schedules, skills and memory. Runs on Cloudflare or self-hosted.

## Plan

- [Kantel plan v2 (27 October 2026)](https://files.myslop.app/6278860afc/harbour-plan-v2-2026-10-27.html): architecture on Pi Durable, Sal's workers first, the Cloudflare and self-hosted targets, and the delivery plan.
- Delivery is tracked as [milestones M0 to M3](https://github.com/tvdavies/harbour/milestones), with one issue per stream. Each issue has its brief, interfaces, dependencies, what it can be built against and its definition of done.
